## How to Execute It in the Practical
- Save the code in a file named student_records.html.

- Double-click the file to open it in any web browser.

- The Proof: You will see the initial table of students. Type a new name and course into the text boxes and click "Add Record"—it will instantly appear in the table. Click the "Delete" button next to any student, and that row will instantly vanish.
