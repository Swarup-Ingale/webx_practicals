## How to Execute It in the Practical
- Ensure both app.js and input.txt are in the same folder.

- Run the file in your terminal:

```Bash
node app.js
```
- The Proof: You will see the Buffer hex codes print in your terminal. More importantly, if you check your folder, Node.js will have magically created a new file called output.txt containing the exact same text as your input.txt
